@startuml
actor User

participant App as UI
participant "Connector Module" as CM
participant "Trip Manager" as TM
participant "Data Access Module" as DAM
database DB

User -> UI: Open "Trips" tab
UI -> CM: GET /trips
CM -> TM: getTrips(userId)

TM -> DAM: fetchTrips(userId)
DAM -> DB: SELECT * FROM trips WHERE userId
DB --> DAM: trip list
DAM --> TM: trip list

TM --> CM: trip list
CM --> UI: Show trips

User -> UI: select Trip
UI -> CM: GET /trip/{id}
CM -> TM: getTripDetails(id)

TM -> DAM: fetchTripDetails(id)
DAM -> DB: SELECT details
DB --> DAM: detail
DAM --> TM: detail
TM --> CM: detail
CM --> UI: Show trip details

@enduml
